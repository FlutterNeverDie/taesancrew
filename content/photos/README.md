# 현장 사진 (회사소개 페이지 "현장 모습")

이 폴더에 사진을 넣으면 빌드할 때 자동으로 사이트에 올라간다.

- **파일 이름 = 순서 + 제목:** `01-천호역 출퇴근 셔틀.jpg`, `02-수진역점 사무실.jpg` 처럼
  - 앞 숫자는 보이는 순서, `-` 뒤가 사진 아래에 보이는 제목
  - 제목 없이 `03.jpg`처럼 넣으면 제목 없이 사진만 보인다
- **사진 형식:** jpg, jpeg, png, webp (아이폰 HEIC는 jpg로 바꿔서)
- 크기는 그대로 넣어도 된다. 빌드할 때 가로 1600px WebP로 줄이고, 촬영 위치(GPS) 같은 정보는 지운다
- 사진을 빼려면 파일을 지우면 된다
- 사람 얼굴이 나오면 동의를 받거나 흐리게 처리한 사진을 넣는다
- 로컬에서 바로 보려면 `npm run photos` (빌드할 때는 자동)
