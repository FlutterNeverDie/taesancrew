# 방문자 통계 켜기 (Cloudflare Web Analytics)

하루에 몇 명이 들어오는지, 어느 페이지를 많이 보는지, 휴대폰/PC 비율, 어디서 들어왔는지(네이버·구글·카톡 등)를 볼 수 있다.

- **무료**이고, 쿠키를 쓰지 않아서 개인정보 동의 창이 필요 없다.
- 사이트 코드는 고칠 필요 없다. Cloudflare 화면에서 켜면 Pages가 알아서 넣는다.

## 켜는 방법 (한 번만)

1. https://dash.cloudflare.com 로그인 (oasa741@gmail.com 계정)
2. 왼쪽 메뉴 **Workers & Pages** → 프로젝트 **taesancrew** 클릭
3. 위쪽 탭 **Metrics** → **Web Analytics** 칸의 **Enable** 버튼
4. 다음 배포부터 적용된다. 바로 적용하려면 Claude에게 "다시 배포해"라고 하거나, Deployments 탭에서 최신 배포의 **Retry deployment**

## 보는 곳

- Cloudflare 왼쪽 메뉴 **Analytics & Logs → Web Analytics** → taesancrew.pages.dev (새 주소 taesan-recruit.com 방문도 여기에 같이 잡힌다. 안 잡히면 Web Analytics에서 taesan-recruit.com 사이트를 추가)
- 처음 몇 시간은 숫자가 비어 있을 수 있다

## 참고

- 도메인을 새로 연결하면 그 도메인도 같은 화면에서 보인다.
- 끄려면 같은 Metrics 탭에서 Disable.
