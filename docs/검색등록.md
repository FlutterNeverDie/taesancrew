# 검색 등록 방법 (네이버·구글)

사이트: https://taesan-recruit.com
사이트 지도: https://taesan-recruit.com/sitemap.xml (페이지·블로그 글이 자동으로 들어간다)

## 0. 도메인을 바꿨을 때 (2026-10-14, taesancrew.pages.dev → taesan-recruit.com)

검색 사이트는 주소마다 따로 등록한다. 새 주소를 아래 1·2번대로 새로 등록하고 사이트맵을 다시 낸다.
예전 주소(taesancrew.pages.dev)로 들어오면 사이트가 새 주소의 같은 페이지로 자동으로 넘겨준다 (`company.oldHosts`).

1. 네이버: 서치어드바이저에 `https://taesan-recruit.com` 새로 등록 → HTML 태그 값을 Claude에게 주면 `company.verification.naver`를 바꾼다 → 소유확인 → 사이트맵·RSS 제출 → 웹 페이지 수집 요청(메인)
2. 구글: 서치콘솔 **속성 추가 → 도메인** → `taesan-recruit.com` → 도메인이 Cloudflare에 있어서 **Cloudflare로 자동 확인**을 누르면 끝 (코드 수정 필요 없음) → Sitemaps에 `https://taesan-recruit.com/sitemap.xml` 제출
3. (선택, 권장) 예전 주소 정식 이전: Cloudflare **Bulk Redirects**로 taesancrew.pages.dev → taesan-recruit.com 301 이동을 걸면, 구글 서치콘솔 예전 속성에서 **설정 → 주소 변경**을 쓸 수 있다. 검색 순위가 새 주소로 더 빨리 옮겨간다
4. 예전 주소 등록(네이버·구글)은 지우지 말고 둔다. 새 주소로 다 옮겨가면 저절로 안 쓰게 된다

## 1. 네이버 서치어드바이저

1. https://searchadvisor.naver.com 접속 → 네이버 로그인 → 상단 **웹마스터 도구**
2. 사이트 등록에 `https://taesan-recruit.com` 입력
3. 소유 확인 방법에서 **HTML 태그** 선택 → `<meta name="naver-site-verification" content="XXXX" />` 의 **XXXX** 값을 복사
4. 그 값을 `src/lib/site.ts` → `company.verification.naver` 에 넣고 커밋 (Claude에게 "네이버 코드 XXXX 넣어줘"라고 해도 됨). 1분 뒤 자동 배포
5. 네이버 화면에서 **소유확인** 클릭
6. 왼쪽 메뉴 **요청 → 사이트맵 제출**: `https://taesan-recruit.com/sitemap.xml`
7. **요청 → 웹 페이지 수집**: 메인 주소 한 번 요청 (첫 노출이 빨라진다)

## 2. 구글 서치콘솔

1. https://search.google.com/search-console 접속 → 구글 로그인 → **속성 추가**
2. **URL 접두어** 선택 → `https://taesan-recruit.com/` 입력
3. 확인 방법 **HTML 태그** → `<meta name="google-site-verification" content="YYYY" />` 의 **YYYY** 값을 복사
4. `src/lib/site.ts` → `company.verification.google` 에 넣고 커밋 → 1분 뒤 배포
5. 구글 화면에서 **확인** 클릭
6. 왼쪽 메뉴 **Sitemaps** → `sitemap.xml` 입력 → 제출

## 3. 새 페이지가 생긴 뒤 할 일 (2026-10-14 추가)

지점 페이지(/branches/gwangju·sujin·cheonho)와 개인정보처리방침이 새로 생겼다. 사이트맵에는 자동으로 들어가 있다.

1. **네이버 RSS 제출:** 서치어드바이저 → 요청 → **RSS 제출** → `https://taesan-recruit.com/blog/rss.xml`
2. **네이버 웹 페이지 수집 요청:** 요청 → **웹 페이지 수집** → 아래 주소를 하나씩 넣기 (하루 50개까지)
   - `/branches/gwangju`, `/branches/sujin`, `/branches/cheonho`
   - `/jobs` (모집 공고가 글자로 바뀜)
3. **네이버 사이트맵 다시 제출:** 요청 → 사이트맵 제출 → `sitemap.xml` (이미 있으면 그대로 두면 된다)
4. **구글 색인 요청:** 서치콘솔 위쪽 검색창에 위 주소를 넣고 **색인 생성 요청**
5. **구글 채용 정보 확인:** https://search.google.com/test/rich-results 에 `https://taesan-recruit.com/jobs` 를 넣어 "채용 정보(JobPosting)"가 보이는지 확인

## 현재 상태

- (2026-10-14) taesan-recruit.com: 네이버·구글 새로 등록할 차례 (위 0번)
- (2026-10-13, 예전 주소 taesancrew.pages.dev 기준) 네이버: 메타태그 방식으로 소유 확인 완료 (`company.verification.naver`)
- 구글: HTML 파일 방식으로 소유 확인 완료 (`public/googleeafb7e09f3b26d3a.html`). Cloudflare Pages가 `.html` 주소를 넘겨버려서 `public/_redirects`로 같은 내용의 txt를 바로 보여준다. **이 두 파일과 _redirects 줄은 지우면 안 된다** (지우면 구글 소유 확인이 풀린다)

## 참고

- 검색 결과에 나오기까지 보통 며칠~2주 걸린다
- 도메인을 또 바꾸면 `company.siteUrl`과 `company.oldHosts`를 바꾸고 두 곳 모두 새 주소로 다시 등록한다 (위 0번)
- 지역 검색("천호역 인력사무소")에는 **네이버 플레이스(지점별 업체 등록)** 가 더 효과가 크다. 지점마다 사업자등록증이 필요
