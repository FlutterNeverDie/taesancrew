3. 페이지별 구성

코드는 영역(area) 단위로 나뉘어 있다. 지도는 src/areas/README.md, 규칙은 CLAUDE.md.

메인 /

  • 첫 화면: "믿을 수 있는 일자리 파트너, 태산크루" + [인력 요청하기] [일자리 찾기], 오른쪽 "지점 안내"판(주소·역 안내·전화)
  • 강조 숫자: 20년+ · 100명+ · 3개 · 10대+
  • 도급사가 다시 찾는 이유 → 약속 한 줄 → 구직자 안내(문자 6항목) → 고객사 로고(두 줄로 흐름) → 유료직업소개소 등록증 → 최근 소식

회사소개 /about · 중점분야 /business · 지점안내 /branches

  • 세 페이지는 상단 탭으로 묶인다 (선택 표시가 다음 탭으로 미끄러짐)
  • 회사소개: 제목 "필요한 날, 필요한 사람을 보냅니다", 대표 사진·인사말, 중점분야·지점 요약 (연혁·지점장 섹션은 삭제)
  • 중점분야: 약속하는 다섯 가지(신속&책임 크게 + 2×2), 서비스, 5단계, 현장 관리, 고객사, 상담
  • 지점안내: 지점별 구글 위치 지도 + 주소·찾아오기·운영시간 + 전화·네이버 지도·카카오맵 버튼

일자리 /jobs

  • "문자 한 통으로 지원하세요" + 보낼 내용 6줄: 성함, 생년월일, 거주지, 희망 집결지, 시작 가능일, 희망 요일
  • [문자 보내기] → 지점 고르는 창(휴대폰은 아래에서 올라옴) → 고른 지점 번호로 양식이 채워진 문자 창
  • 근무 조건 표, 지점 연락처(전화·문자 지원), 채용 전단(누르면 크게), 고객사, FAQ

소식 /blog

  • 2026년 1월부터 두 달에 한 번꼴로 8개 글. 글은 content/blog/*.md 파일 하나가 글 하나. 글 안에 읽기 진행 막대

자주 묻는 질문 /faq · Contact /contact · 등록증 /awards · 404

  • FAQ: 기업 / 일하려는 분 두 묶음, 답이 부드럽게 펼쳐짐
  • Contact: 기업 전용 폼(회사명·담당자·연락처·필요 인원·근무지·내용). 제출하면 대표번호로 보낼 문자를 만든다 (휴대폰은 문자 앱, PC는 번호·내용·복사)
  • 등록증: 지점별 등록증 이미지(누르면 크게) + 등록번호
  • 없는 주소: "페이지를 찾을 수 없어요" + 메인·일자리·지점 안내 버튼

5. 디자인과 움직임

  • 색: 남색(#011A4A 중심) + 안전 노랑. 글꼴: 제목 Paperlogy, 본문 Pretendard
  • 글씨는 크게: 설명 문장 text-lg 이상, 작고 흐린 글씨 금지
  • 움직임은 짧고 조용하게: 첫 화면 순서대로 등장, 스크롤하면 살며시 나타나기, 고객사 로고 흐르기, 페이지 전환 크로스페이드, 헤더 그림자, 휴대폰 메뉴·FAQ 부드럽게 열기, 마우스 올림 효과(등록증 떠오르기, 소식 밑줄, PC 메뉴 밑줄)
  • 휴대폰의 "동작 줄이기" 설정을 켠 사람에게는 움직이지 않는다

6. 기술·배포·검색

  • Next.js 16 정적 사이트 + Tailwind 4. 저장소 github.com/FlutterNeverDie/taesancrew
  • 배포: main에 올리면 GitHub Actions가 Cloudflare Pages로 자동 배포(약 1분). Vercel 무료 요금제는 상업적 사용 금지라 옮김
  • 이미지는 WebP(cwebp), 제목 글꼴은 사이트에 직접, 본문 글꼴은 CDN. 정적 파일은 public/_headers로 오래 캐시
  • 검색: 네이버 서치어드바이저·구글 서치콘솔 소유 확인과 사이트맵 제출 완료 (docs/검색등록.md). 회사·지점 정보를 구조화 데이터(JSON-LD)로 넣음
  • Lighthouse(휴대폰): 성능 86~93, 접근성·권장사항·검색 100 (2026-10-14)
  • 방문자 통계: Cloudflare Web Analytics (docs/방문자통계.md)
