1. 개요

회사명태산크루 (TS CREW) - 상호 확정. 경기광주점 등록증 상호는 아직 "태산 인크루트"
지점수진역점 · 천호점 · 경기광주점
사업 종목인력알선, 유료직업소개소, 기타도급 (경기광주점 등록증 기준)
업종인력 공급·소개 (인력사무소)
운영 형태가족 사업

타깃별 목표

타깃누구사이트에서 얻어야 할 것최종 행동
화주사·도급사 (B2B)인력이 필요한 업체, 하청을 주는 원청공급 규모, 대응 속도, 안전관리, 수상·인증 등 믿을 근거인력 요청 / 견적 문의
개인 구직자일용직·단기 근로를 찾는 개인가까운 지점, 일당·지급 방식, 업무 종류, 등록 절차전화 / 근무 등록
  • 브랜드 변경(태산 인크루트 → 태산크루)을 사이트에서 자연스럽게 알려, 기존 거래처와 인력이 혼란 없이 찾아오게 합니다.

강조할 5가지 (확정)

  1. 오랜 경력 - 물류업계 20년 이상 현장 노하우
  2. 3개 직영 지점 - 경기 광주·성남·서울 동부 권역에서 근로자 모집
  3. 하루 100명 이상 투입
  4. 신속 & 책임 - 근로자 문제 시 소장이 직접 현장 방문, 24시간 연중무휴 도급사 의견 청취
  5. 맞춤형 인력 + 안전교육 - 경력자 우선 배치, 안전교육 후 투입

참고 자료: 회사소개서 PDF(서비스 경쟁력, 차별화 포인트, 배치 프로세스, 주요 고객사 30곳), 수진역점·천호점 채용 전단 6장.

3. 페이지별 상세 기획

메인에서 방문자가 "기업" 또는 "구직자"로 갈라지도록 설계합니다. 모든 페이지 하단과 모바일 하단 고정 바에 전화하기 / 문의하기 버튼을 둡니다.

3-1. 메인 /

  1. 히어로: 한 줄 슬로건 + 버튼 2개 - "인력이 필요해요"(기업) / "일자리 찾아요"(구직자)
  2. 숫자로 보는 태산크루: 업력, 누적 파견 인원, 거래처 수, 지점 3곳
  3. 수상·인증 하이라이트: 대표 상장 3~4개 카드 → 전체 보기
  4. 주요 거래처 로고 띠 (게재 동의받은 곳만)
  5. 최신 블로그 글 3개
  6. 지점 3곳 요약 (주소·전화·지도 링크)

3-2. 회사소개 /about

  • 대표 인사말, 연혁(2023년 11월 태산 인크루트 경기광주점 개업 → 태산크루 리브랜딩), 비전·핵심가치
  • 브랜드 스토리: 왜 "태산크루"인지 한 문단

3-3. 수상·인증 /awards

  • 상장·감사패·인증서·등록증을 갤러리로 전시, 클릭하면 크게 보기
  • 카드마다 수여일·수여 기관·한 줄 설명, 최신순 정렬
  • 직업소개소 등록증 등 법적 자격도 여기에 (기업 고객 신뢰에 가장 중요)

3-4. 기업 고객 /business

  • 서비스 분야: 물류·건설·제조 등 실제 공급 업종
  • 제공 형태 두 가지: 인력 공급(필요한 인원만 보내기)과 도급(작업 단위로 맡아서 처리). 등록증에 기타도급이 있어 도급사 대상 어필 가능
  • 강점: 당일 배치 속도, 3개 지점 인력풀, 안전교육·보험, 정산 방식
  • 이용 절차: 문의 → 상담 → 계약 → 배치 → 정산
  • 납품 실적·거래처 사례, 기업용 문의 폼

3-5. 구직자 /jobs

  • 하는 일 종류, 하루 흐름(출근 → 배치 → 근무 → 지급), 당일지급 여부
  • 처음 오는 분 안내: 준비물(신분증, 안전화, 기초안전보건교육증)
  • 자주 묻는 질문(FAQ)
  • 간단 등록 폼: 이름·연락처·희망 지점·경력 정도
  • 글자 크게, 전화 버튼 크게 - 중장년층·외국인 근로자도 쉽게

3-6. 지점 안내 /branches

  • 지점별 카드: 주소, 전화, 운영시간, 대중교통, 지도(네이버·카카오맵 링크), 사무실 사진
  • 지점별 상세 페이지(/branches/gwangju 등)는 "천호역 인력사무소", "경기광주 인력사무소" 같은 지역 검색에 유리

3-7. 블로그 /blog

  • 목록(카테고리 필터) + 글 상세. 기능은 아래 4번 참고

3-8. 문의 /contact

  • 탭 2개: 기업 문의 / 구직 문의
  • 제출 시 담당자에게 알림(이메일 또는 카카오 알림톡)
  • 개인정보 수집 동의 체크박스 필수

4. 블로그 기능

처음에는 마크다운 파일로 글을 쓰고 배포하는 방식으로 시작하고, 가족분들이 직접 올려야 하면 관리자 화면(CMS)을 붙이는 걸 권합니다.

방식글 쓰는 사람비용장점단점
A. 마크다운 파일 (추천 시작안)개발자(직접)무료빠르고 검색 노출 좋음, 서버 필요 없음비개발자는 글 올리기 어려움
B. 헤드리스 CMS (Sanity, Decap 등)누구나 웹에서무료~저렴관리자 화면에서 글·사진 업로드초기 설정 필요
C. 자체 백엔드 + DB누구나서버비문의 관리 등 확장 자유개발·운영 부담 큼

카테고리 예시

  • 현장 소식 - 배치 현장, 지점 일상
  • 기업 인사이트 - 인력 운영 팁, 노무·안전 이슈 (B2B 검색 유입)
  • 구직 가이드 - 처음 일용직 하는 법, 안전교육 받는 법 (구직자 검색 유입)
  • 공지 - 리브랜딩, 지점 소식, 수상 소식

글 하나에 들어갈 항목

제목, 날짜, 카테고리, 대표 이미지, 요약(검색 결과·공유 미리보기용), 본문, 관련 글 3개.

5. 디자인 방향

  • 톤: 믿음직하고 깔끔하게. 인력사무소 특유의 전단지 느낌은 피하고, 기업 고객에게 "체계적인 회사"로 보이게.
  • 컬러: 로고 컬러 기반. 로고 받기 전엔 남색(신뢰) + 포인트 주황(활력) 가안.
  • 모바일 우선: 구직자 대부분이 휴대폰으로 접속. 하단 고정 "전화하기" 버튼.
  • 실사 사진: 실제 현장·사무실·직원 사진이 스톡 사진보다 신뢰도가 높음.
  • 글자 크기: 본문 16~17px 이상, 구직자 페이지는 더 크게.

6. 기술 스택

항목선택이유
프레임워크React + Next.js (정적 export)React 그대로 쓰면서 페이지마다 HTML이 미리 만들어져 네이버·구글 검색 노출에 유리. 순수 React(Vite)는 검색엔진이 내용을 잘 못 읽음
언어 · 스타일TypeScript · Tailwind CSS유지보수, 빠른 반응형 작업
블로그MDX 파일 → 이후 CMS4번 참고
문의 폼Formspree 등 폼 서비스 또는 서버리스 함수서버 없이 이메일 수신

도메인예: taesancrew.co.kr구매 필요
검색 등록네이버 서치어드바이저, 구글 서치콘솔, 네이버 플레이스(지점 3곳)지역 검색 노출의 핵심

기존 태산 인크루트 홈페이지·도메인이 있다면 새 사이트로 연결(리다이렉트)해야 검색 순위를 이어받습니다.
