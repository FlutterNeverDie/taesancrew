# 상단 메뉴바

- **영역 경로:** `src/areas/layout/header/`
- **보이는 곳:** 모든 페이지 맨 위
- **파일:** `index.tsx`
- **내용:** 로고(심볼+"태산 리크루트 & 태산크루"), 메뉴, 대표번호 노란 버튼. 회사소개에 마우스를 올리면 하위 메뉴(중점분야·지점안내·연혁)
- **데이터:** 메뉴 = site.ts `nav`, 번호 = `company.mainPhone`, 로고 = components/Logo.tsx
- **주의:** 클라이언트 컴포넌트(모바일 메뉴 열림 상태). 메뉴 항목은 여기서 말고 site.ts `nav`에서 고친다

수정은 이 폴더 안에서만. 다른 영역도 쓰는 값(회사 정보·지점·고객사·질문)은 `src/lib/site.ts`에서 고친다.
