# 지점 페이지 찾아오는 길

- **영역 경로:** `src/areas/branch/info/`
- **보이는 곳:** /branches/<지점>
- **파일:** `index.tsx`
- **내용:** 구글 위치 지도 + 주소·찾아오기·대표·직업소개소 등록번호 + 네이버/카카오 지도
- **데이터:** site.ts `branches[]`(주소·대표·등록번호), 사전의 `branchPage`, `mapQuery`

수정은 이 폴더 안에서만. 다른 영역도 쓰는 값(회사 정보·지점·고객사·질문)은 `src/lib/site.ts`에서 고친다.
