# 고객사 로고 벽

- **영역 경로:** `src/areas/shared/client-wall/`
- **보이는 곳:** 메인·중점분야·일자리
- **파일:** `index.tsx`
- **내용:** 로고를 "보이는 면적"이 비슷하게 맞춰 격자로 보여준다. 로고 없는 회사는 이름 글자. 다른 언어 화면은 `nameEn`(영문 이름)으로 보인다
- **데이터:** site.ts `clients` (순서 = 화면 순서, w/h = 로고 픽셀 크기), 로고 파일 public/images/clients/*.webp
- **주의:** 앞으로 뺄 회사는 `clients` 배열 위로. 전체 로고 크기는 이 파일의 `AREA`(면적) 값. 새 로고는 흰 여백을 잘라 PNG로 넣고 w/h를 적는다

수정은 이 폴더 안에서만. 다른 영역도 쓰는 값(회사 정보·지점·고객사·질문)은 `src/lib/site.ts`에서 고친다.
