# 비자별 근무 안내

- **영역 경로:** `src/areas/visa/body/`
- **보이는 곳:** /visa (메인 "처음이어도 괜찮아요" 목록의 "외국인 가능" 링크)
- **파일:** `index.tsx`
- **내용:** 첫 화면(외국인 가능 + 한국어 대화 필요) → 가능 / 확인 필요 / 어려움 3묶음 비자 목록 → 확인처(1345, 하이코리아, 법무부) → 참고한 자료(출처 링크) → 지원 안내
- **데이터:** `src/i18n/visa/` (원본 `ko.ts` + 12개 언어 번역 `<언어>.ts`, 구조가 다르면 빌드 실패)
- **주의:** 법령이 자주 바뀐다. 바뀌면 13개 언어 파일 모두 `updated`(기준일)와 내용, 근거를 같이 고친다. 확실하지 않은 건 "확인 필요"로 두고 단정하지 않는다

수정은 이 폴더 안에서만. 다른 영역도 쓰는 값(회사 정보·지점·고객사·질문)은 `src/lib/site.ts`에서 고친다.
