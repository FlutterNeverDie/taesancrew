# 메인 첫 화면 + 지점별 집결지 배차판

- **영역 경로:** `src/areas/home/hero/`
- **보이는 곳:** / 맨 위
- **파일:** `index.tsx`
- **내용:** 왼쪽 "필요한 날, 필요한 사람을 보냅니다" + 버튼 2개, 오른쪽 지점별 집결지(지점명·권역·찾아오는 길·전화)
- **데이터:** `branches` (본점이 맨 앞)
- **주의:** 노란색은 배차판 머리와 전화 버튼에만. `?grad` 주소면 남색 그라데이션(.brand-hero)

수정은 이 폴더 안에서만. 다른 영역도 쓰는 값(회사 정보·지점·고객사·질문)은 `src/lib/site.ts`에서 고친다.
