# 출근하는 날 하루 흐름

- **영역 경로:** `src/areas/jobs/day/`
- **보이는 곳:** /jobs 근무 조건 아래
- **파일:** `index.tsx`
- **내용:** 집결 → 셔틀 → 안전교육 → 작업 → 점심 → 퇴근 → 급여 7단계 (휴대폰 세로, PC 가로) + 준비물
- **데이터:** 사전의 `jobs.dayTitle·dayDesc·day·bringTitle·bring·bringNote`
- **주의:** 소식 글 "물류센터 일, 처음이라면"과 근무 조건에 있는 사실만 쓴다. 시간·일급 금액은 넣지 않는다. 단계를 바꾸면 13개 언어 모두 같은 개수로

수정은 이 폴더 안에서만. 다른 영역도 쓰는 값(회사 정보·지점·고객사·질문)은 `src/lib/site.ts`에서 고친다.
